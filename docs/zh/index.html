写 Markdown，

SwiftDown 是一款原生 macOS Markdown 编辑器：行内编辑、实时预览、代码高亮、数学公式与 Mermaid 图表，全部离线可用。

在 Mac App Store 下载 反馈与支持

需要 macOS 15 或更高版本 · 支持 Apple 芯片和 Intel

写作所需，一应俱全

一款专注的编辑器，从随手笔记到技术文档都能胜任。

  • ✍️

    所见即所得的行内编辑

    格式在输入处直接渲染。选中文字弹出浮动工具栏，也可以用 ⌘B、⌘I 等熟悉的快捷键。

  • 🧩

    轻松编辑表格

    直接在单元格里编辑，点一下就能增加行和列，不用再数竖线。

  • 💻

    代码高亮

    围栏代码块在编辑器和预览中都有语法高亮。

  • ∑

    数学公式

    支持行内 $...$ 与块级 $$...$$ 公式，输入即渲染。

  • 📊

    Mermaid 图表

    流程图、时序图等直接从 Mermaid 代码块渲染出来。

  • 🗂️

    标题折叠

    折叠长段落，用 ⌃⌘↑ / ⌃⌘↓ 快速升降标题级别。

  • 🖼️

    本地与网络图片

    相对路径的本地图片和网络图片都能直接显示。

  • 🔤

    尊重原文件

    自动识别文件编码，保存时保留原有编码和换行符。

  • 📄

    导出 PDF

    按 ⇧⌘E 把任意文档导出为整洁的 PDF。

  • 🎨

    随心定制

    调整字号、行高、图片尺寸、表格样式和配色，编辑器与预览保持一致。

四种视图模式

随时在「显示」菜单或用快捷键切换，每个文件会记住上次使用的模式。

模式 快捷键 说明
行内编辑⌘1所见即所得，默认模式
源码⌘2纯 Markdown 源码，带语法着色
分栏⌘3左侧编辑、右侧预览，滚动同步
预览⌘4只看渲染结果

行内编辑适用于 64 KB 以内的文件，更大的文件会以分栏模式打开。

轻量、流畅、私密

一款原生 Mac 应用，不打扰你的写作，也不碰你的文档。

  • 🪶

    生来轻量

    基于 macOS 原生技术构建，不内置浏览器引擎，体积小，占用内存和电量都更少。

  • 🚀

    大文件也流畅

    数 MB 的文档也能顺畅打开，解析在后台进行，输入和滚动都不卡顿。

  • 🔒

    文档只留在你的 Mac 上

    所有处理都在本地完成，渲染资源随应用打包。唯一的网络请求，是加载文档中引用的网络图片。
