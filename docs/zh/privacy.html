隐私政策

生效日期：2026 年 10 月 6 日

简而言之：SwiftDown 不收集、不存储、不共享任何个人数据，你的文档不会离开你的 Mac。

我们收集的数据

无。SwiftDown 没有用户账户，不包含任何统计分析、广告、追踪或崩溃上报服务，也不会把你的文档或使用信息发送给我们或任何第三方。

你的文档

所有编辑、渲染、代码高亮、数学公式和图表生成都在你的 Mac 本地完成，所需资源全部内置在应用中。应用只会在你选择的位置读取和保存文件。粘贴或拖入图片时，SwiftDown 会把图片复制到文档旁的 .assets 文件夹中。快速查看和访达缩略图扩展只在访达请求预览时，于本地渲染 Markdown 文件。

保存在你 Mac 上的数据

为了正常工作，SwiftDown 会在自己的沙盒目录中保存少量数据，这些数据不会离开你的设备：

  • 你的偏好设置，例如字号、行高和配色
  • 每个文件上次使用的视图模式，以及是否显示大纲侧栏
  • 你授予的文件夹访问权限，以便本地图片无需重复授权即可加载
  • 可编辑的欢迎文档

删除应用即会一并删除这些数据。

网络访问

SwiftDown 只会为了加载文档中引用的网络图片而发起网络请求（例如 ![](https://example.com/image.png)）。这些请求由你的 Mac 直接发往图片所在的服务器。和任何网页请求一样，该服务器可以看到你的 IP 地址和标准请求信息。SwiftDown 不会在这些请求中附带 Cookie 或任何文档内容。如果文档中没有网络图片，SwiftDown 不会发起任何网络请求。

第三方服务

SwiftDown 不包含任何收集数据的第三方 SDK。如果你通过 GitHub 联系我们，你提交的内容适用 GitHub 隐私声明。请不要在 issue 中附带含有个人或机密信息的文档。

儿童隐私

SwiftDown 不收集任何人的个人信息，包括 13 岁以下的儿童。

政策变更

如本政策有所变更，我们会更新此页面及上方的生效日期。
