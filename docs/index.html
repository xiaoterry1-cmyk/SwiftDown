Write Markdown.
See it as you type.

SwiftDown is a native Markdown editor for macOS. WYSIWYG inline editing, live preview, code highlighting, math, and Mermaid diagrams. Everything works offline.

Download on the Mac App Store Feedback & support

Requires macOS 15 or later · Apple silicon and Intel

Everything you need to write

A focused editor that handles plain notes, technical docs, and everything in between.

  • ✍️

    Inline WYSIWYG editing

    Formatting renders right where you type. Select text for a floating toolbar, or use familiar shortcuts like ⌘B and ⌘I.

  • 🧩

    Tables made easy

    Edit cells in place and add rows and columns with a click, without counting pipes.

  • 💻

    Code highlighting

    Fenced code blocks get syntax highlighting in both the editor and preview.

  • ∑

    Math formulas

    Write inline $...$ and block $$...$$ formulas and see them rendered instantly.

  • 📊

    Mermaid diagrams

    Flowcharts, sequence diagrams, and more render directly from Mermaid code blocks.

  • 🗂️

    Heading folding

    Collapse long sections and promote or demote headings with ⌃⌘↑ / ⌃⌘↓.

  • 🖼️

    Local and web images

    Images with relative paths and images from the web both display inline.

  • 🔤

    Respects your files

    Encodings are detected automatically, and saving keeps the original encoding and line endings.

  • 📄

    Export to PDF

    Turn any document into a clean PDF with ⇧⌘E.

  • 🎨

    Make it yours

    Adjust font size, line height, image sizes, table style, and colors. The editor and preview stay in step.

Four ways to view

Switch any time from the View menu or with a shortcut. Each file remembers the mode you last used.

Mode Shortcut What it does
Source⌘1Plain Markdown with syntax coloring
Split⌘2Editor and preview side by side, scrolling in sync
Preview⌘3Rendered output only
Inline⌘4WYSIWYG editing, the default mode

Inline mode is available for files up to 64 KB. Larger files open in Split mode.

Light, fast, and private

A native Mac app that stays out of your way and keeps your documents to yourself.

  • 🪶

    Lightweight by design

    Built with native macOS technologies instead of a bundled browser engine, so it stays small and easy on memory and battery.

  • 🚀

    Smooth at any size

    Multi-megabyte documents open smoothly, and parsing runs in the background so typing and scrolling never stall.

  • 🔒

    Your documents stay on your Mac

    Everything is processed locally, with all rendering resources bundled in the app. The only network requests load images your documents link to on the web.
